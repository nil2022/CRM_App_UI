## Introduction

Welcome to the **Customer Relationship Management (CRM) Software**, a robust platform designed to help customers register and manage issues they encounter. This is an open-source project, inviting enthusiastic developers to contribute and enhance its capabilities.

---

## Features

Streamline customer support with the following powerful features:

- **Registration**: Easy sign-up for new users.
- **Login**: Secure access to the platform.
- **Dashboard**: Centralized view of all activities.
- **Profile**: Manage personal user information.
- **Tickets**: Track and monitor customer issues.
- **Create Ticket**: Submit new support requests.
- **Update Ticket**: Modify existing ticket details.
- **Assign Engineer**: Allocate tickets to support staff.
- **Close Ticket**: Resolve and archive completed issues.
- **Change Password**: Update account security settings.

## Getting Started

Interested in contributing or setting up the project locally? Follow these steps:

1. **Clone the repository**: `git clone <repository-url>`
2. **Install dependencies**: `npm install`
3. **Run the development server**: `npm run dev`
4. Explore the app at `http://localhost:3001`
